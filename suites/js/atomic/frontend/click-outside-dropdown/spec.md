Build an element that detects clicks outside of itself.

* **Dropdown Container** (`data-testid="dropdown-menu"`).
* **Behavior**: Listen to global document click events; close dropdown if the click target is outside `dropdown-menu`.

For `base-react-js`, implement the UI in `src/App.jsx`.

For `base-next-js`, implement the UI in `app/page.jsx` as a client component (`"use client"`).
