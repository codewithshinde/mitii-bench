Build a mini custom audio player interface.

* **Controls**: Play/Pause (`data-testid="play-pause-btn"`).
* **Progress Bar** (`data-testid="audio-progress"`): Reflects percentage elapsed.
* **Time Display** (`data-testid="time-display"`): Shows `mm:ss`.

For `base-react-js`, implement the UI in `src/App.jsx`.

For `base-next-js`, implement the UI in `app/page.jsx` as a client component (`"use client"`).
