Build a directory file tree viewer.

* **Folder Item** (`data-testid="folder-[id]"`): Click to expand/collapse sub-files.
* **File Item** (`data-testid="file-[id]"`): Displays file icon and title.

For `base-react-js`, implement the UI in `src/App.jsx`.

For `base-next-js`, implement the UI in `app/page.jsx` as a client component (`"use client"`).
