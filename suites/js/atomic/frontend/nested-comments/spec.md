Build a recursive comment thread module.

* **Comment Item** (`data-testid="comment-[id]"`).
* **Reply Button** (`data-testid="reply-btn-[id]"`): Opens inline reply text input.
* **Nested List**: Indents child replies directly under parent comment.

For `base-react-js`, implement the UI in `src/App.jsx`.

For `base-next-js`, implement the UI in `app/page.jsx` as a client component (`"use client"`).
