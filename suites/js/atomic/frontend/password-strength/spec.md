Build an interactive password evaluation field.

* **Input** (`data-testid="password-input"`).
* **Meter Display** (`data-testid="strength-meter"`): Updates visual score (Weak, Medium, Strong) based on length, numbers, and special characters.

For `base-react-js`, implement the UI in `src/App.jsx`.

For `base-next-js`, implement the UI in `app/page.jsx` as a client component (`"use client"`).
