Build an auto-focus search bar.

* **Search Input** (`data-testid="search-input"`).
* **Focus Button** (`data-testid="focus-btn"`): Clicking this programmatically focuses the search input using React `useRef`.

For `base-react-js`, implement the UI in `src/App.jsx`.

For `base-next-js`, implement the UI in `app/page.jsx` as a client component (`"use client"`).
